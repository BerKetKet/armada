## 3. Deviations from Brief

1. **Batch Push for CI Verification:** Commits `d8179da` through `ee5a9a5` were committed after each numbered step and verified locally with `./gradlew test` and `./scripts/check-deps.sh`. They were pushed together in a single batch to `origin master`. CI run `38510415282` ran against the tip commit `ee5a9a5`, so intermediate commits did not receive individual CI runs.
2. **`android:exported="true"` on MainActivity:** MainActivity retains `android:exported="true"` in `AndroidManifest.xml`. As permitted by the brief clause ("Set android:exported="false" on the activity unless a reason is written in the report"), `MainActivity` is the application's primary launcher activity with intent filter `<action android:name="android.intent.action.MAIN" /><category android:name="android.intent.category.LAUNCHER" />`. Setting `android:exported="false"` on a launcher activity causes Android OS launchers to fail with a `SecurityException` when attempting to start the activity.
3. **Piped Stream Reader Handling in SessionTest:** In Java, `PipedInputStream` checks whether the writer thread is alive; if the writer thread dies without closing `PipedOutputStream`, reading throws `IOException: Write end dead` instead of returning EOF (`-1`). In `SessionTest`, `startSession` wraps `session.run()` in a `try-finally` that explicitly closes the server-side output stream upon session exit, cleanly reflecting the real-world behavior of closing the underlying socket upon disconnect.

## 4. Open Questions

1. **Root Service Autostart:** Currently, the root daemon must be manually launched via `app_process` under `su`. In future milestones (e.g. 0.4+), an automated startup helper or Magisk service daemon may be needed for boot persistence.
2. **Abstract Socket Namespace Visibility:** The abstract socket namespace (`armada.daemon`) is scoped to Linux network namespaces. When apps run inside isolated or private network namespaces (or work profiles), abstract socket connection may be isolated. Testing on physical devices with different root managers (Magisk vs KernelSU vs APatch) will verify namespace accessibility.

+sealed class DaemonStatus {
+    data class Connected(val version: Int) : DaemonStatus()
+    object Denied : DaemonStatus()
+    data class Unreachable(val exceptionClass: String) : DaemonStatus()
+}
+
+object DaemonClassifier {
+    const val SOCKET_NAME: String = "armada.daemon"
+
+    fun classifyStreams(inputStream: InputStream, outputStream: OutputStream): DaemonStatus {
+        return try {
+            val reader = FrameReader(inputStream)
+            val writer = FrameWriter(outputStream)
+
+            val firstLine = reader.readFrame()
+                ?: return DaemonStatus.Unreachable("EOFException")
+            val firstMsg = try {
+                Messages.decode(firstLine)
+            } catch (e: Exception) {
+                return DaemonStatus.Unreachable(e.javaClass.simpleName)
+            }
+
+            if (firstMsg is Message.Failure) {
+                return if (firstMsg.code == Protocol.DENIED) {
+                    DaemonStatus.Denied
+                } else {
+                    DaemonStatus.Unreachable("ProtocolException")
+                }
+            }
+
+            if (firstMsg !is Message.Hello) {
+                return DaemonStatus.Unreachable("ProtocolException")
+            }
+
+            val version = firstMsg.v
+
+            // Send Hello back
+            try {
+                writer.writeFrame(Messages.encode(Message.Hello(Protocol.VERSION)))
+            } catch (e: Exception) {
+                return DaemonStatus.Unreachable(e.javaClass.simpleName)
+            }
+
+            // Check if daemon sent a denied error frame
+            val secondLine = try {
+                reader.readFrame()
+            } catch (e: Exception) {
+                null
+            }
+
+            if (secondLine != null) {
+                val secondMsg = try {
+                    Messages.decode(secondLine)
+                } catch (e: Exception) {
+                    null
+                }
+                if (secondMsg is Message.Failure && secondMsg.code == Protocol.DENIED) {
+                    return DaemonStatus.Denied
+                }
+            }
+
+            DaemonStatus.Connected(version)
+        } catch (e: Throwable) {
+            DaemonStatus.Unreachable(e.javaClass.simpleName)
+        }
+    }
+}

+    fun run(args: Array<String>): Int {
+        if (args.isEmpty()) {
+            printUsage("No command specified.")
+            return EXIT_USAGE
+        }
+
+        val command = args[0]
+        return when (command) {
+            "hello" -> handleHello(args)
+            "echo" -> handleEcho(args)
+            else -> {
+                printUsage("Unknown command '$command'.")

+    private fun handleHello(args: Array<String>): Int {
+        if (args.size != 1) {
+            printUsage("The 'hello' command takes no additional arguments.")
+            return EXIT_USAGE
+        }
+
+        return execute { reader, writer ->
+            // Handshake: server sends Hello(v) first
+            val serverHelloFrame = reader.readFrame()
+                ?: throw IllegalStateException("Connection closed before greeting received")
+            val serverMsg = Messages.decode(serverHelloFrame)
+            if (serverMsg is Message.Failure) {
+                printError(serverMsg)
+                return@execute EXIT_ERROR
+            }
+            if (serverMsg !is Message.Hello) {
+                printErrorJson("handshake", Protocol.BAD_REQUEST, "Expected hello from daemon, got: $serverHelloFrame")
+                return@execute EXIT_ERROR
+            }
+
+            // Client sends Hello(Protocol.VERSION)
+            writer.writeFrame(Messages.encode(Message.Hello(Protocol.VERSION)))
+
+            // Print the result data as one JSON line to stdout and exit 0
+            val resultData = JsonObject("v" to JsonNumber(serverMsg.v.toLong()))
+            out.println(JsonWriter.write(resultData))
+            EXIT_OK
+        }
+    }
+
+    private fun handleEcho(args: Array<String>): Int {
+        if (args.size < 2) {
+            printUsage("Missing text argument for 'echo'. Usage: echo <text> [--delay-ms N]")
+            return EXIT_USAGE
+        }
+
+        val text = args[1]
+        var delayMs = 0L
+
+        var i = 2
+        while (i < args.size) {
+            val arg = args[i]
+            when {
+                arg == "--delay-ms" -> {
+                    if (i + 1 >= args.size) {
+                        printUsage("Missing value for --delay-ms.")
+                        return EXIT_USAGE
+                    }
+                    val parsed = args[i + 1].toLongOrNull()
+                    if (parsed == null || parsed < 0L) {
+                        printUsage("Invalid value for --delay-ms: '${args[i + 1]}'. Must be a non-negative integer.")
+                        return EXIT_USAGE
+                    }
+                    delayMs = parsed
+                    i += 2
+                }
+                arg.startsWith("--delay-ms=") -> {
+                    val rawVal = arg.substringAfter("--delay-ms=")
+                    val parsed = rawVal.toLongOrNull()
+                    if (parsed == null || parsed < 0L) {
+                        printUsage("Invalid value for --delay-ms: '$rawVal'. Must be a non-negative integer.")
+                        return EXIT_USAGE
+                    }
+                    delayMs = parsed
+                    i += 1
+                }
+                else -> {
+                    printUsage("Unknown option '$arg'. Usage: echo <text> [--delay-ms N]")
+                    return EXIT_USAGE
+                }
+            }
+        }
+
+        return execute { reader, writer ->
+            // Handshake
+            val serverHelloFrame = reader.readFrame()
+                ?: throw IllegalStateException("Connection closed before greeting received")
+            val serverMsg = Messages.decode(serverHelloFrame)
+            if (serverMsg is Message.Failure) {
+                printError(serverMsg)
+                return@execute EXIT_ERROR
+            }
+            if (serverMsg !is Message.Hello) {
+                printErrorJson("handshake", Protocol.BAD_REQUEST, "Expected hello from daemon, got: $serverHelloFrame")
+                return@execute EXIT_ERROR
+            }
+            writer.writeFrame(Messages.encode(Message.Hello(Protocol.VERSION)))
+
+            // Send Request
+            val reqId = "cli-" + System.currentTimeMillis()
+            val toolArgs = if (delayMs > 0L) {
+                JsonObject(
+                    "text" to JsonString(text),
+                    "delayMs" to JsonNumber(delayMs)
+                )
+            } else {
+                JsonObject(
+                    "text" to JsonString(text)
+                )
+            }
+            writer.writeFrame(Messages.encode(Message.Request(id = reqId, tool = "echo", args = toolArgs)))
+
+            // Read until terminal message
+            while (true) {
+                val line = reader.readFrame()
+                    ?: throw IllegalStateException("Connection closed before response received")
+                val msg = Messages.decode(line)
+                when (msg) {
+                    is Message.Progress -> {
+                        // Incremental progress ignored by default CLI
+                        continue
+                    }
+                    is Message.Result -> {
+                        out.println(JsonWriter.write(msg.data))
+                        return@execute EXIT_OK
+                    }
+                    is Message.Failure -> {
+                        printError(msg)
+                        return@execute EXIT_ERROR
+                    }
+                    else -> {
+                        printErrorJson(reqId, Protocol.BAD_REQUEST, "Unexpected message: $line")
+                        return@execute EXIT_ERROR
+                    }
+                }
+            }
+            @Suppress("UNREACHABLE_CODE")
+            EXIT_OK
+        }
+    }
+
+    private fun execute(action: (FrameReader, FrameWriter) -> Int): Int {
+        val conn = try {
+            socketProvider.open(SOCKET_NAME)
+        } catch (e: Throwable) {
+            printErrorJson("handshake", Protocol.FAILED, "Cannot connect to $SOCKET_NAME: ${e.message ?: e.javaClass.simpleName}")
+            return EXIT_ERROR
+        }
+
+        return try {
+            val reader = FrameReader(conn.inputStream)
+            val writer = FrameWriter(conn.outputStream)
+            action(reader, writer)
+        } catch (e: Throwable) {
+            printErrorJson("handshake", Protocol.FAILED, e.message ?: e.javaClass.simpleName)
+            EXIT_ERROR
+        } finally {
+            try {
+                conn.close()
+            } catch (ignored: Exception) {
+            }
+        }
+    }
+

+        val json = Messages.encode(failure)
+        err.println(json)
+    }

+        val json = Messages.encode(Message.Failure(id = id, code = code, message = message))
+        err.println(json)
+    }

+        err.println("  echo <text> [--delay-ms N] Echo text with optional delay in milliseconds")
+    }

+        if (text.length > 4096) {
+            throw ProtocolException(Protocol.BAD_ARGS, "text length exceeds 4096 characters")
+        }
+        val delayMs = args.optLong("delayMs", default = 0L, min = 0L, max = 10000L) ?: 0L

+            var elapsed = 0L

+                if (ctx.isCancelled || Thread.currentThread().isInterrupted) {
+                    throw InterruptedException("cancelled")
+                }
+                val step = minOf(10L, delayMs - elapsed)
+                sleeper(step)
+                elapsed = clock() - start
+            }
+            if (ctx.isCancelled || Thread.currentThread().isInterrupted) {
+                throw InterruptedException("cancelled")
+            }
+            ctx.progress(
+                JsonObject(
+                    "seq" to JsonNumber(1L),
+                    "elapsedMs" to JsonNumber(elapsed)
+                )
+            )
+        }

+    private fun performHandshake(): Boolean {
+        // On connect, the daemon sends {"type":"hello","v":1} first.
+        try {
+            send(Message.Hello(Protocol.VERSION))
+        } catch (e: Exception) {
+            return false
+        }
+

+        if (!peerIsRoot) {
+            try {
+                send(Message.Failure(id = Protocol.HANDSHAKE_ID, code = Protocol.DENIED, message = "peer is not root"))
+            } catch (ignored: Exception) {
+            }
+            return false
+        }

+            reader.readFrame()
+        } catch (e: FrameTooLongException) {
+            return false
+        } catch (e: TruncatedFrameException) {
+            return false
+        } catch (e: MalformedFrameException) {
+            try {
+                send(Message.Failure(id = Protocol.HANDSHAKE_ID, code = Protocol.BAD_REQUEST, message = "malformed frame: ${e.message}"))
+            } catch (ignored: Exception) {

+            return false
+        }
+
+        if (handshakeLine == null) {
+            return false
+        }
+
+        val handshakeMsg = try {
+            Messages.decode(handshakeLine)
+        } catch (e: Throwable) {
+            try {
+                send(Message.Failure(id = Protocol.HANDSHAKE_ID, code = Protocol.BAD_REQUEST, message = "invalid handshake: ${e.message}"))
+            } catch (ignored: Exception) {
+            }
+            return false
+        }
+
+        if (handshakeMsg !is Message.Hello || handshakeMsg.v != Protocol.VERSION) {
+            try {
+                send(Message.Failure(id = Protocol.HANDSHAKE_ID, code = Protocol.BAD_REQUEST, message = "handshake failed: expected hello with v=${Protocol.VERSION}"))
+            } catch (ignored: Exception) {
+            }
+            return false
+        }
+
+        return true
+    }

+    private fun readLoop() {
+        while (true) {
+            val frame = try {
+                reader.readFrame() ?: break
+            } catch (e: FrameTooLongException) {
+                break
+            } catch (e: TruncatedFrameException) {
+                break
+            } catch (e: MalformedFrameException) {
+                try {
+                    send(Message.Failure(id = Protocol.HANDSHAKE_ID, code = Protocol.BAD_REQUEST, message = "malformed frame: ${e.message}"))
+                } catch (ignored: Exception) {

+                val errId = extractedId ?: Protocol.HANDSHAKE_ID
+                send(Message.Failure(id = errId, code = Protocol.BAD_REQUEST, message = e.message ?: "decode error"))

+            }

+        }
+    }

+                } else null

+        } catch (ignored: Exception) {

+        }
+    }

+            is Message.Request -> handleRequest(message)
+            is Message.Cancel -> handleCancel(message)

+                send(Message.Failure(id = Protocol.HANDSHAKE_ID, code = Protocol.BAD_REQUEST, message = "unexpected hello after handshake"))
+            }
+            is Message.Progress -> {
+                send(Message.Failure(id = message.id, code = Protocol.BAD_REQUEST, message = "unexpected message type: progress"))
+            }
+            is Message.Result -> {
+                send(Message.Failure(id = message.id, code = Protocol.BAD_REQUEST, message = "unexpected message type: result"))
+            }
+            is Message.Failure -> {
+                send(Message.Failure(id = message.id, code = Protocol.BAD_REQUEST, message = "unexpected message type: error"))
+            }
+        }
+    }
+
+    private fun handleRequest(message: Message.Request) {
+        val task = RequestTask(message.id)
+        val existing = inFlight.putIfAbsent(message.id, task)
+        if (existing != null) {
+            send(Message.Failure(id = message.id, code = Protocol.BAD_REQUEST, message = "duplicate in-flight id"))
+            return
+        }
+
+        val tool = dispatcher.find(message.tool)
+        if (tool == null) {
+            inFlight.remove(message.id)
+            send(Message.Failure(id = message.id, code = Protocol.UNKNOWN_TOOL, message = "unknown tool: ${message.tool}"))
+            return
+        }
+
+        executor.execute {
+            task.thread = Thread.currentThread()
+            val ctx = object : ToolContext {
+                override val isCancelled: Boolean
+                    get() = task.cancelled.get() || Thread.currentThread().isInterrupted
+
+                override fun progress(data: JsonObject) {
+                    if (!task.terminalSent.get() && !task.cancelled.get()) {
+                        synchronized(writeLock) {
+                            if (!task.terminalSent.get() && !task.cancelled.get()) {
+                                sendLocked(Message.Progress(id = message.id, data = data))
+                            }
+                        }
+                    }
+                }
+            }
+
+            try {
+                val result = tool.run(message.args, ctx)
+                if (task.terminalSent.compareAndSet(false, true)) {
+                    synchronized(writeLock) {
+                        sendLocked(Message.Result(id = message.id, data = result))
+                    }
+                }
+            } catch (e: ProtocolException) {
+                if (task.terminalSent.compareAndSet(false, true)) {
+                    synchronized(writeLock) {
+                        sendLocked(Message.Failure(id = message.id, code = e.code, message = e.message ?: e.code))
+                    }
+                }
+            } catch (e: InterruptedException) {
+                if (task.terminalSent.compareAndSet(false, true)) {
+                    synchronized(writeLock) {
+                        sendLocked(Message.Failure(id = message.id, code = Protocol.CANCELLED, message = "request cancelled"))
+                    }
+                }
+            } catch (e: Throwable) {
+                if (task.cancelled.get() || Thread.currentThread().isInterrupted) {
+                    if (task.terminalSent.compareAndSet(false, true)) {
+                        synchronized(writeLock) {
+                            sendLocked(Message.Failure(id = message.id, code = Protocol.CANCELLED, message = "request cancelled"))
+                        }
+                    }
+                } else {
+                    if (task.terminalSent.compareAndSet(false, true)) {
+                        synchronized(writeLock) {
+                            sendLocked(Message.Failure(id = message.id, code = Protocol.FAILED, message = e.message ?: e.javaClass.simpleName))
+                        }
+                    }
+                }
+            } finally {
+                inFlight.remove(message.id)
+                task.thread = null
+            }
+        }
+    }
+
+    private fun handleCancel(message: Message.Cancel) {
+        val task = inFlight[message.id] ?: return
+        task.cancel()
+        if (task.terminalSent.compareAndSet(false, true)) {
+            synchronized(writeLock) {
+                sendLocked(Message.Failure(id = message.id, code = Protocol.CANCELLED, message = "request cancelled"))
+            }
+        }
+    }
+
+    private fun send(message: Message) {
+        synchronized(writeLock) {
+            sendLocked(message)
+        }
+    }
+
+    private fun sendLocked(message: Message) {
+        val text = Messages.encode(message)
+        writer.writeFrame(text)
+    }
+
+    private fun cleanup() {
+        for (task in inFlight.values) {
+            task.cancel()
+        }
+        inFlight.clear()
+    }

+                        is Message.Result -> {
+                            terminalCounts.merge(msg.id, 1, Int::plus)

+                        is Message.Failure -> {

+# Armada Root Daemon
+
+The Armada root daemon runs as a privileged process (effective UID 0) on Android, providing background network services and tools over a line-delimited JSON Unix domain stream socket in the abstract namespace (`armada.daemon`).
+
+---
+
+## 1. Starting the Daemon
+
+The daemon is packaged inside the Armada APK (`io.github.berketket.armada`) and executed using Android's `app_process` runtime under root (`su`).
+
+### Exact Start Command
+
+```sh

+## 3. Handshake and Security Rules
+
+Communication takes place over the abstract Unix domain socket `armada.daemon`.
+
+1. **Daemon Greeting:** Upon accepting a new client connection, the daemon sends `{"type":"hello","v":1}`.
+2. **Root Credential Enforcement:**
+   - The daemon inspects peer credentials using `LocalSocket.getPeerCredentials()`.
+   - If `peer.uid != 0`, the daemon immediately sends a handshake error and closes the connection without processing any client frames:
+     ```json
+     {"type":"error","id":"handshake","code":"denied","message":"peer is not root"}
+     ```
+3. **Client Handshake Reply:**
+   - A root client must reply with `{"type":"hello","v":1}` matching `Protocol.VERSION`.
+   - If the client sends an invalid greeting, unexpected message type, or mismatched version `v`, the daemon sends an error with `id: "handshake"` and closes the connection:
+     ```json
+     {"type":"error","id":"handshake","code":"bad_request","message":"handshake failed: expected hello with v=1"}
+     ```
+4. **Error ID Extraction Rule:**
+   - When decoding incoming frames after the handshake, if a frame fails parsing or decoding, the daemon extracts the `"id"` string field from the raw JSON object if present.
+   - If a valid `id` is extracted, the failure response uses that `id`.
+   - If the frame is malformed JSON, not an object, or contains no extractable `id`, the error response uses `id: "handshake"`.
+5. **Duplicate In-Flight IDs:**
+   - If a request arrives with an `id` matching a currently in-flight request, the daemon rejects the second request with code `bad_request` (`duplicate in-flight id`) and leaves the first request running.
+6. **Cancellation Semantics:**
+   - Sending `{"type":"cancel","id":"<id>"}` interrupts the worker thread running that request. The daemon emits a terminal error message with code `cancelled`.
+   - Cancelling an `id` that is not currently in flight is silently ignored to prevent race conditions when a request has already completed.
+
+---
+
+## 4. Known Limits and Invariants
+
+1. **Frame Length Limit:** 1 MiB (1,048,576 bytes) max frame length. Oversize frames raise `FrameTooLongException` and terminate the session.
+2. **JSON Nesting Depth:** Maximum nesting depth of 64 levels. Nesting depth 65 is rejected.
+3. **Echo Tool Limits:**
+   - `text`: Required string, max length 4,096 characters (longer text returns `bad_args`).
+   - `delayMs`: Optional integer, range 0 to 10,000 milliseconds (values > 10,000 or < 0 return `bad_args`).
+4. **Lifecycle Guarantee:** Every request produces exactly one terminal message (`result` or `error`). Progress messages are guaranteed never to arrive after the terminal message for that request ID.
