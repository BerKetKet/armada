## 3. Runner vs Local Machine Differences Observed

1. **POSIX awk compatibility**: On Ubuntu GitHub runners, `/usr/bin/awk` is `mawk`, which does not support the 3-argument `match()` function. Replacing it with standard POSIX `match()` and `substr()` ensures identical behavior.
2. **Missing SDK components on runner**: The `ubuntu-latest` runner provides `ANDROID_HOME` at `/usr/local/lib/android/sdk`, but required licenses and target components (`platforms;android-35`, `build-tools;35.0.0`) must be explicitly installed via `sdkmanager`.
3. **Clean Cache Metadata Resolution**: On local development environments, Gradle caches parent POMs and BOMs for plugins across builds. In a fresh runner container, Gradle downloads and verifies these parent POMs and BOMs (`guava-parent:33.4.0-jre`, `junit-bom:5.10.2`, `junit-bom:5.11.0-M2`, `groovy-bom:4.0.29`). They were added to `verification-metadata.xml`.
