## 3. Deviations from Brief

1. **JDK Guard in KotlinCompile**: Setting `-Xjdk-release=8` initially failed because Gradle/KGP default JVM toolchain target was Java 21, resulting in: `e: '-Xjdk-release=8' option conflicts with '-jvm-target 21'`. Configuring `JavaVersion.VERSION_1_8` and `jvmTarget.set(JvmTarget.JVM_1_8)` in `proto/build.gradle.kts` resolved the conflict and successfully enforced JDK 8 signatures.
2. **JDK Guard Verification Method**: The brief suggested `removeLast()` or `List.of(...)`. Testing showed `removeLast()` on `MutableList` is available via Kotlin stdlib extension function since Kotlin 1.4, so it compiles even under JDK 8. `java.util.List.of("a")` was used as the proof of compile-time rejection of Java 9+ JDK APIs.
3. **Data Class Constructor Visibility**: `JsonNumber` was initially declared with a `private` primary constructor, which triggered a Kotlin compiler warning (`Non-public primary constructor is exposed via the generated 'copy()' method of the 'data' class`). The constructor was made public and the `init` block validates that exactly one of `longValue` or `doubleValue` is non-null, cleanly eliminating the warning.
4. **Interactive CLI Prompt in Background Task**: Running `gh run watch` without an explicit run ID prompted for interactive selection when multiple runs were active; the background task was killed and immediately re-launched with the specific run ID `38501882663` and `38503381962`.
5. **Brief 0.2.2 Commit / CI Order**: In Brief 0.2.2, Part 1 code commit `ae6019c` was committed locally but not pushed immediately; Part 2 code commit `815b177` was committed next, and both code commits were pushed together to origin master. CI ran on commit `815b177` (run `38505462337`), so commit `ae6019c` did not have an isolated CI push run.

### Remaining Protocol Statements Without Direct Tests
The following normative statements in `docs/protocol.md` do not have direct unit tests in `:proto` and are tracked as open questions for upcoming milestones:
1. *Lifecycle invariant 1 (Single Terminal Message):* `docs/protocol.md` section 5 states: "Every request sent to the daemon produces exactly one terminal message: either a result message or an error message."
   - **Target module:** Belongs to daemon dispatch logic in milestone 0.3 (`:daemon`).
2. *Lifecycle invariant 2 (Progress Sequencing):* `docs/protocol.md` section 5 states: "Progress messages may only arrive before the terminal message, never after it."
   - **Target module:** Belongs to daemon dispatch logic in milestone 0.3 (`:daemon`).
3. *Lifecycle invariant 3 (Cancellation Error):* `docs/protocol.md` section 5 states: "When a cancel message is processed for an in-flight request, the daemon terminates the task and responds with an error message with code 'cancelled'."
   - **Target module:** Belongs to daemon dispatch logic in milestone 0.3 (`:daemon`).
4. *Tool Name Prose vs Regex Mismatch:* In `docs/protocol.md` section 2, tool name is described in prose as "1 to 64 lowercase alphanumeric ASCII characters matching `^[a-z][a-z0-9_.]{0,63}$`". In code and regex, `tool` characters include `.` and `_` which are punctuation/symbols rather than strictly alphanumeric. The regex is authoritative in `:proto` and tested in `MessagesTest.invalidToolsAreRejected`. Aligning the prose description belongs to documentation updates.
5. *Protocol Evolution Principles:* `docs/protocol.md` section 6 evolution principles (bumping version on breaking changes) are policy specifications that apply to multi-version daemon deployments.

## 9. Brief 0.2.2 and 0.2.3 Fixes and CI Verification

### Part 1: Hello Version Overflow (Brief 0.2.2)
- **Problem:** `Messages.decode` converted the `"v"` field via `longValue.toInt()`. Any value where `(v.toLong().toInt()) == 1` (such as `4294967297L`, which is `2^32 + 1`) was silently accepted as version 1 instead of being rejected.
- **Failing inputs:**
  - `{"type":"hello","v":4294967297}` (overflows to 1)
  - `{"type":"hello","v":4294967296}` (overflows to 0)
  - `{"type":"hello","v":2147483648}` (overflows to negative)
  - `{"type":"hello","v":0}`
  - `{"type":"hello","v":-1}`
- **Accepted boundary inputs:**
  - `{"type":"hello","v":1}`
  - `{"type":"hello","v":2147483647}` (`Int.MAX_VALUE`)
- **Fix:** `Messages.kt` checks that `vLong` satisfies `vLong in 1L..Int.MAX_VALUE.toLong()` before converting to `Int`, throwing `ProtocolException(Protocol.BAD_REQUEST, ...)` otherwise without truncation.
- **Regression test name:** `MessagesTest.helloVersionRangeEnforcement`

### Part 2: Lone Surrogates on the Writer (Brief 0.2.2)
- **Problem:** `JsonWriter.writeString` wrote lone UTF-16 surrogates directly into the output buffer. When encoded to UTF-8 for wire framing, JVM UTF-8 charset encoders replace unpaired surrogates with the Unicode replacement character (`'?'` / `U+FFFD`), corrupting the payload on the wire.
- **Failing inputs:**
  - Lone high surrogates: `"\uD800"`, `"\uD83D"`, `"\uD800abc"`, `"abc\uD800"`, `"\uD83D\u0041"`, `"\uD800\uD800"`
  - Lone low surrogates: `"\uDC00"`, `"\uDFFF"`, `"\uDC00abc"`, `"abc\uDC00"`, `"\uDC00\uD800"`
- **Accepted valid inputs:**
  - Valid surrogate pair: `"\uD83D\uDE00"` (U+1F600 emoji) written and round-tripped as valid JSON
  - Line/paragraph separators: `"\u2028"` and `"\u2029"` preserved escaped and equal on round-trip
- **Fix:** `JsonWriter.writeString` inspects characters and validates surrogate pairs: high surrogates `\uD800..\uDBFF` must be immediately followed by low surrogates `\uDC00..\uDFFF`. Unpaired high or low surrogates immediately throw `JsonException` with their character index as `position`. Valid pairs are written as-is. `docs/protocol.md` section 1 was updated to state: `- **Surrogates:** Encoders reject lone surrogates.`
- **Regression test names:**
  - `JsonConformanceTest.writerRejectsLoneHighSurrogate`
  - `JsonConformanceTest.writerRejectsLoneLowSurrogate`
  - `JsonConformanceTest.writerAcceptsValidSurrogatePairAndRoundTrips`
  - `JsonConformanceTest.writerKeepsU2028AndU2029EscapedAndEqualOnRoundTrip`

### Part 3: CRLF Frame Ending and Exact 1 MiB Frame Limit (Brief 0.2.3)
- **Problem:** `FramingTest` lacked explicit assertions for non-blank frames terminated by `\\r\\n` and the exact 1 MiB byte boundary on `FrameReader`.
- **Inputs tested:**
  - `{"type":"cancel","id":"r1"}\\r\\n` returns payload without `\\r` and then `null` on EOF.
  - Exactly 1,048,576 ASCII `'a'` bytes followed by `\\n` is accepted and returned as 1 MiB frame.
  - 1,048,577 ASCII `'a'` bytes followed by `\\n` throws `FrameTooLongException`.
- **Regression test names:**
  - `FramingTest.nonBlankFrameTerminatedByCrLfIsReturnedWithoutCr`
  - `FramingTest.exactOneMiBFrameIsAcceptedAndOneByteMoreIsRejected`

+# Armada Wire Protocol Specification
+
+Version: 1
+
+The Armada wire protocol defines communication between clients (the Android UI app or the CLI client) and the root daemon. It operates over a stream connection (such as a Unix domain local socket) using line-delimited JSON.
+
+---
+
+## 1. Framing and Transport
+
+- **Encoding:** Strict UTF-8. Malformed UTF-8 sequences are rejected as framing errors.
+- **Surrogates:** Encoders reject lone surrogates.
+- **Framing:** Line-delimited. Each frame is a single UTF-8 line terminated by `\n` (0x0A) or optional `\r\n` (0x0D 0x0A).
+- **Line Contents:** A single compact JSON object. No raw newline characters may appear within a frame.
+- **Blank Lines:** Empty or whitespace-only lines are ignored by the reader.
+- **Maximum Frame Length:** 1 MiB (1,048,576 bytes). If a frame line exceeds this limit, the reader raises `FrameTooLongException` and the connection must be closed.
+- **Stream Termination:** If the stream terminates without a trailing newline while bytes are buffered, `TruncatedFrameException` is raised.
+
+---
+
+## 2. Limits and Validation
+
+- **Maximum Nesting Depth:** 64 levels for objects and arrays. Nesting depth 65 is rejected.
+- **Maximum Payload Size:** 1 MiB (1,048,576 bytes) per JSON document.
+- **Identifier (`id`):** 1 to 64 ASCII characters matching `^[A-Za-z0-9._-]{1,64}$`.
+- **Tool Name (`tool`):** 1 to 64 lowercase alphanumeric ASCII characters matching `^[a-z][a-z0-9_.]{0,63}$`.
+- **Extra Fields:** Unknown fields in message objects are ignored to maintain forward compatibility.
+- **Numbers:** Integers within the 64-bit signed range `[-9223372036854775808, 9223372036854775807]` decode to `Long`. Floating-point numbers decode to finite `Double`. Leading zeros, leading plus signs (`+1`), leading decimal points (`.5`), trailing decimal points (`1.`), bare minuses (`-`), hex notation, NaN, and Infinity are strictly rejected.
+
+---
+
+## 3. Message Types
+
+Every message on the wire is a JSON object with a required `"type"` string property.
+
+### 3.1 Hello (`hello`)
+Exchanged at handshake to negotiate protocol versions.
+
+```json
+{"type":"hello","v":1}
+```
+
+- `v` (integer, required): Protocol version (must be >= 1).
+
+### 3.2 Request (`request`)
+Sent by the client to invoke a tool.
+
+```json
+{"type":"request","id":"r1","tool":"ping","args":{"host":"1.1.1.1","count":4}}
+```
+
+- `id` (string, required): Request correlation identifier (1..64 chars `[A-Za-z0-9._-]`).
+- `tool` (string, required): Target tool name matching `[a-z][a-z0-9_.]*`.
+- `args` (object, required): Tool-specific arguments object.
+
+### 3.3 Cancel (`cancel`)
+Sent by the client to cancel an ongoing request.
+
+```json
+{"type":"cancel","id":"r1"}
+```
+
+- `id` (string, required): Identifier of the request to cancel.
+
+### 3.4 Progress (`progress`)
+Sent by the daemon to report incremental streaming output before request completion.
+
+```json
+{"type":"progress","id":"r1","data":{"seq":1,"rttMs":12.4}}
+```
+
+- `id` (string, required): Request correlation identifier.
+- `data` (object, required): Incremental progress payload.
+
+### 3.5 Result (`result`)
+Sent by the daemon to signal successful terminal completion of a request.
+
+```json
+{"type":"result","id":"r1","data":{"sent":4,"received":4}}
+```
+
+- `id` (string, required): Request correlation identifier.
+- `data` (object, required): Final result payload.
+
+### 3.6 Failure (`error`)
+Sent by the daemon to signal terminal failure of a request. The wire type is `"error"`.
+
+```json
+{"type":"error","id":"r1","code":"bad_args","message":"count must be 1..100"}
+```
+
+- `id` (string, required): Request correlation identifier.
+- `code` (string, required): Error code from the closed set defined below.
+- `message` (string, required): Human-readable error description.
+
+---
+
+## 4. Error Codes
+
+Error codes form a closed set of string constants:
+
+| Error Code | Meaning |
+|---|---|
+| `bad_request` | Malformed frame, JSON syntax error, missing required field, wrong field type, or unknown message type. |
+| `unknown_tool` | The requested tool name is not registered or supported by the daemon. |
+| `bad_args` | Arguments supplied in `args` failed validation (e.g. missing required arg, type mismatch, out of range). |
+| `denied` | Permission denied or caller UID unauthorized for the requested operation. |
+| `unsupported` | Feature or kernel capability not available on the current device. |
+| `failed` | Tool executed but failed during execution (command failure, network error, etc.). |
+| `timeout` | Operation timed out before completion. |
+| `cancelled` | Request was cancelled by the client via a `cancel` message. |
+| `internal` | Unexpected daemon internal error or unhandled failure. |
+
+---
+
+## 5. Lifecycle and Terminal Message Invariants
+
+1. **Exactly One Terminal Message:** Every `request` sent to the daemon produces exactly one terminal message: either a `result` message or an `error` message.
+2. **Progress Sequencing:** A daemon may emit zero or more `progress` messages for an `id` while the request is running. Progress messages may only arrive before the terminal message, never after it.
+3. **Cancellation:** When a `cancel` message is processed for an in-flight request, the daemon terminates the task and responds with an `error` message with code `"cancelled"`.
+
+---
+
+## 6. Protocol Evolution Rules
+
+- **Compatible Changes (Minor):**
+  - Adding optional fields to message objects or data payloads. Parsers ignore unknown fields.
+  - Adding new tools or new optional arguments to existing tools.
+- **Incompatible Changes (Major):**
+  - Removing, renaming, or changing the type or semantics of an existing field.
+  - Altering framing delimiters, JSON syntax constraints, or existing error codes.
+  - Any incompatible change requires incrementing `Protocol.VERSION`.

+                if (lineEnd > bufferStart && buffer[lineEnd - 1] == '\r'.code.toByte()) {

+                }

+                val line = decodeUtf8(buffer, bufferStart, lineLen)
+                bufferStart = newlineIndex + 1

+                    bufferStart = 0
+                    bufferEnd = 0
+                }

+                if (line.isNotBlank()) {
+                    return line
+                }
+                // Skip blank lines
+                continue
+            }
+
+            val pendingBytes = bufferEnd - bufferStart
+            if (pendingBytes > maxBytes) {
+                throw FrameTooLongException("Frame exceeds maximum length of $maxBytes bytes without newline ($pendingBytes bytes)")
+            }
+
+            if (isEof) {
+                if (pendingBytes == 0) {
+                    return null
+                } else {
+                    throw TruncatedFrameException("Stream terminated without newline delimiter ($pendingBytes pending bytes)")
+                }
+            }
+
+            compactBufferIfNeeded()
+            val bytesRead = inputStream.read(readBuf)
+            if (bytesRead == -1) {
+                isEof = true
+                if (bufferEnd == bufferStart) {
+                    return null
+                } else {
+                    throw TruncatedFrameException("Stream terminated without newline delimiter (${bufferEnd - bufferStart} pending bytes)")
+                }
+            } else if (bytesRead > 0) {
+                appendBytes(readBuf, 0, bytesRead)
+                val newPending = bufferEnd - bufferStart
+                if (newPending > maxBytes) {
+                    val nl = findNewline()
+                    if (nl == -1 || nl - bufferStart > maxBytes) {
+                        throw FrameTooLongException("Frame exceeds maximum length of $maxBytes bytes without newline ($newPending bytes)")
+                    }
+                }
+            }
+        }
+    }

+    private fun decodeUtf8(bytes: ByteArray, offset: Int, length: Int): String {
+        return try {
+            utf8Decoder.reset()
+            val inBuf = ByteBuffer.wrap(bytes, offset, length)
+            utf8Decoder.decode(inBuf).toString()
+        } catch (e: CharacterCodingException) {
+            throw MalformedFrameException("Malformed UTF-8 sequence in frame", e)
+        }
+    }
+
+    private fun findNewline(): Int {
+        for (i in bufferStart until bufferEnd) {
+            if (buffer[i] == '\n'.code.toByte()) {
+                return i
+            }
+        }
+        return -1
+    }
+

+        if (bufferStart > 0) {
+            val remaining = bufferEnd - bufferStart
+            if (remaining > 0) {
+                System.arraycopy(buffer, bufferStart, buffer, 0, remaining)
+            }
+            bufferStart = 0
+            bufferEnd = remaining
+        }
+    }
+
+    private fun appendBytes(src: ByteArray, offset: Int, len: Int) {
+        if (bufferEnd + len > buffer.size) {
+            val newCapacity = maxOf(buffer.size * 2, bufferEnd + len)
+            val newBuf = ByteArray(newCapacity)
+            System.arraycopy(buffer, 0, newBuf, 0, bufferEnd)
+            buffer = newBuf
+        }
+        System.arraycopy(src, offset, buffer, bufferEnd, len)
+        bufferEnd += len
+    }

+        }
+        val bytes = payload.toByteArray(StandardCharsets.UTF_8)
+        outputStream.write(bytes)
+        outputStream.write('\n'.code)
+        outputStream.flush()
+    }

+                ch in '\uDC00'..'\uDFFF' -> {
+                    throw JsonException("Lone low surrogate", position = i)
+                }
+                ch == '"' -> sb.append("\\\"")
+                ch == '\\' -> sb.append("\\\\")
+                ch == '\b' -> sb.append("\\b")
+                ch == '\u000c' -> sb.append("\\f")
+                ch == '\n' -> sb.append("\\n")
+                ch == '\r' -> sb.append("\\r")
+                ch == '\t' -> sb.append("\\t")
+                ch < ' ' -> appendHex4(ch.code, sb)
+                ch == '\u2028' -> sb.append("\\u2028")
+                ch == '\u2029' -> sb.append("\\u2029")
+                else -> sb.append(ch)
+            }
+            i++
+        }
+        sb.append('"')
+    }
+
+    private fun appendHex4(code: Int, sb: StringBuilder) {
+        sb.append("\\u")
+        sb.append(HEX_CHARS[(code shr 12) and 0xF])
+        sb.append(HEX_CHARS[(code shr 8) and 0xF])
+        sb.append(HEX_CHARS[(code shr 4) and 0xF])
+        sb.append(HEX_CHARS[code and 0xF])
+    }

+    data class Cancel(val id: String) : Message()
+    data class Progress(val id: String, val data: JsonObject) : Message()

+    data class Failure(val id: String, val code: String, val message: String) : Message()

+    private val ID_REGEX = Regex("^[A-Za-z0-9._-]{1,64}$")
+    private val TOOL_REGEX = Regex("^[a-z][a-z0-9_.]{0,63}$")

+    fun encode(message: Message): String {
+        val obj = when (message) {
+            is Message.Hello -> {
+                if (message.v < 1) {
+                    throw ProtocolException(Protocol.BAD_REQUEST, "Protocol version must be >= 1")
+                }
+                JsonObject(
+                    "type" to JsonString("hello"),
+                    "v" to JsonNumber(message.v.toLong())
+                )
+            }
+            is Message.Request -> {
+                validateId(message.id)
+                validateTool(message.tool)
+                JsonObject(
+                    "type" to JsonString("request"),
+                    "id" to JsonString(message.id),
+                    "tool" to JsonString(message.tool),
+                    "args" to message.args
+                )
+            }
+            is Message.Cancel -> {
+                validateId(message.id)
+                JsonObject(
+                    "type" to JsonString("cancel"),
+                    "id" to JsonString(message.id)
+                )
+            }
+            is Message.Progress -> {

+                    "data" to message.data
+                )
+            }
+            is Message.Result -> {

+                    "type" to JsonString("result"),
+                    "id" to JsonString(message.id),
+                    "data" to message.data
+                )
+            }
+            is Message.Failure -> {
+                validateId(message.id)
+                validateCode(message.code)
+                JsonObject(
+                    "type" to JsonString("error"),
+                    "id" to JsonString(message.id),
+                    "code" to JsonString(message.code),
+                    "message" to JsonString(message.message)

+            }
+        }

+    fun decode(line: String): Message {

+            JsonParser.parse(line)
+        } catch (e: JsonException) {
+            throw ProtocolException(Protocol.BAD_REQUEST, e.message ?: "Invalid JSON", e)
+        }
+
+        if (root !is JsonObject) {
+            throw ProtocolException(Protocol.BAD_REQUEST, "Message must be a JSON object")
+        }
+
+        val typeVal = root["type"] ?: throw ProtocolException(Protocol.BAD_REQUEST, "Missing required 'type' field")
+        if (typeVal !is JsonString) {
+            throw ProtocolException(Protocol.BAD_REQUEST, "Field 'type' must be a string")
+        }
+
+        return when (val type = typeVal.value) {
+            "hello" -> {
+                val vVal = root["v"] ?: throw ProtocolException(Protocol.BAD_REQUEST, "Missing required 'v' field")
+                if (vVal !is JsonNumber || !vVal.isLong) {
+                    throw ProtocolException(Protocol.BAD_REQUEST, "Field 'v' must be an integer")
+                }
+                val vLong = vVal.longValue!!
+                if (vLong < 1L || vLong > Int.MAX_VALUE.toLong()) {
+                    throw ProtocolException(Protocol.BAD_REQUEST, "Field 'v' must be between 1 and ${Int.MAX_VALUE}")
+                }
+                Message.Hello(vLong.toInt())
+            }
+            "request" -> {
+                val id = extractId(root)
+                val toolVal = root["tool"] ?: throw ProtocolException(Protocol.BAD_REQUEST, "Missing required 'tool' field")
+                if (toolVal !is JsonString) {
+                    throw ProtocolException(Protocol.BAD_REQUEST, "Field 'tool' must be a string")
+                }
+                val tool = toolVal.value
+                validateTool(tool)
+                val argsVal = root["args"] ?: throw ProtocolException(Protocol.BAD_REQUEST, "Missing required 'args' field")
+                if (argsVal !is JsonObject) {
+                    throw ProtocolException(Protocol.BAD_REQUEST, "Field 'args' must be an object")
+                }
+                Message.Request(id, tool, argsVal)
+            }
+            "cancel" -> {
+                val id = extractId(root)
+                Message.Cancel(id)
+            }
+            "progress" -> {
+                val id = extractId(root)
+                val dataVal = root["data"] ?: throw ProtocolException(Protocol.BAD_REQUEST, "Missing required 'data' field")
+                if (dataVal !is JsonObject) {
+                    throw ProtocolException(Protocol.BAD_REQUEST, "Field 'data' must be an object")
+                }
+                Message.Progress(id, dataVal)
+            }
+            "result" -> {
+                val id = extractId(root)
+                val dataVal = root["data"] ?: throw ProtocolException(Protocol.BAD_REQUEST, "Missing required 'data' field")
+                if (dataVal !is JsonObject) {
+                    throw ProtocolException(Protocol.BAD_REQUEST, "Field 'data' must be an object")
+                }
+                Message.Result(id, dataVal)
+            }
+            "error" -> {
+                val id = extractId(root)
+                val codeVal = root["code"] ?: throw ProtocolException(Protocol.BAD_REQUEST, "Missing required 'code' field")
+                if (codeVal !is JsonString) {
+                    throw ProtocolException(Protocol.BAD_REQUEST, "Field 'code' must be a string")
+                }
+                val code = codeVal.value
+                validateCode(code)
+                val msgVal = root["message"] ?: throw ProtocolException(Protocol.BAD_REQUEST, "Missing required 'message' field")
+                if (msgVal !is JsonString) {
+                    throw ProtocolException(Protocol.BAD_REQUEST, "Field 'message' must be a string")
+                }
+                Message.Failure(id, code, msgVal.value)
+            }
+            else -> throw ProtocolException(Protocol.BAD_REQUEST, "Unknown message type '$type'")
+        }
+    }
+
+    private fun extractId(obj: JsonObject): String {
+        val idVal = obj["id"] ?: throw ProtocolException(Protocol.BAD_REQUEST, "Missing required 'id' field")
+        if (idVal !is JsonString) {
+            throw ProtocolException(Protocol.BAD_REQUEST, "Field 'id' must be a string")
+        }
+        val id = idVal.value
+        validateId(id)
+        return id
+    }
+
+    private fun validateId(id: String) {
+        if (!ID_REGEX.matches(id)) {
+            throw ProtocolException(Protocol.BAD_REQUEST, "Invalid message id '$id': must be 1..64 chars of [A-Za-z0-9._-]")
+        }
+    }
+
+    private fun validateTool(tool: String) {
+        if (!TOOL_REGEX.matches(tool)) {
+            throw ProtocolException(Protocol.BAD_REQUEST, "Invalid tool name '$tool': must match [a-z][a-z0-9_.]* and be 1..64 chars")
+        }
+    }
+
+    private fun validateCode(code: String) {
+        if (!Protocol.ERROR_CODES.contains(code)) {
+            throw ProtocolException(Protocol.BAD_REQUEST, "Unknown error code '$code'")
+        }
+    }

+                } catch (e: JsonException) {

+    private fun mutate(base: String, random: Random, mutateChars: String): String {
+        val type = random.nextInt(4)
+        val sb = java.lang.StringBuilder(base)
+
+        when (type) {
+            0 -> {
+                // Char flip/replacement
+                if (sb.isNotEmpty()) {
+                    val idx = random.nextInt(sb.length)
+                    sb.setCharAt(idx, mutateChars[random.nextInt(mutateChars.length)])
+                }
+            }
+            1 -> {
+                // Truncation
+                if (sb.isNotEmpty()) {
+                    val cut = random.nextInt(sb.length)
+                    sb.setLength(cut)
+                }
+            }
+            2 -> {
+                // Insertion
+                val idx = if (sb.isEmpty()) 0 else random.nextInt(sb.length)
+                val char = mutateChars[random.nextInt(mutateChars.length)]
+                sb.insert(idx, char)
+            }
+            3 -> {
+                // Bit flip on a random char code
+                if (sb.isNotEmpty()) {
+                    val idx = random.nextInt(sb.length)
+                    val flipped = (sb[idx].code xor (1 shl random.nextInt(8))).toChar()
+                    sb.setCharAt(idx, flipped)
+                }
+            }
+        }
+        return sb.toString()

+        return when (kind) {
+            0 -> JsonNull

+                    val l = when (random.nextInt(4)) {

+                        1 -> random.nextInt(100).toLong()
+                        2 -> random.nextLong()
+                        else -> -random.nextInt(100).toLong()
+                    }
+                    JsonNumber(l)
+                } else {
+                    // Double (avoid -0.0 and Infinity/NaN)
+                    var d = (random.nextDouble() - 0.5) * 1000.0
+                    if (d == -0.0) d = 0.0
+                    JsonNumber(d)
+                }
+            }
+            3 -> {
+                // String
+                val len = random.nextInt(15)
+                val sb = StringBuilder()
+                for (i in 0 until len) {
+                    when (random.nextInt(5)) {
+                        0 -> sb.append(('a'..'z').random())
+                        1 -> sb.append(('A'..'Z').random())
+                        2 -> sb.append(('0'..'9').random())
+                        3 -> sb.append(" _-./:")
+                        else -> sb.append("\\\"")
+                    }
+                }
+                JsonString(sb.toString())
+            }
+            4 -> {
+                // Array
+                val size = random.nextInt(4)
+                val elements = ArrayList<JsonValue>(size)
+                for (i in 0 until size) {
+                    elements.add(generateRandomValue(depth + 1, random))
+                }

+            }
+            else -> {

+                val map = LinkedHashMap<String, JsonValue>(size)

+                    val key = "key_${depth}_$i"
+                    map[key] = generateRandomValue(depth + 1, random)
+                }
+                JsonObject(map)
+            }
+        }
