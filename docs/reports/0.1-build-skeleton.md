# Report 0.1: Build Skeleton

## 1. What changed

- `.gitignore`: Ignore Gradle, build output, Android Studio/IDE files, keystores, and `local.properties`.
- `gradle/wrapper/gradle-wrapper.properties`: Configure Gradle wrapper pinned to 9.6.0.
- `gradlew`, `gradlew.bat`: Standard Gradle wrapper scripts.
- `settings.gradle.kts`: Configure plugin and dependency resolution management with google() and mavenCentral(), declare root project name and include modules `:app`, `:proto`, `:daemon`, `:cli`.
- `build.gradle.kts`: Configure root build with AGP 9.4.1 and Kotlin JVM 2.4.10 plugins.
- `proto/build.gradle.kts`: Build configuration for desktop Kotlin JVM library with JUnit 4.13.2 test dependency.
- `proto/src/main/kotlin/app/armada/proto/ProtoPlaceholder.kt`: Placeholder class for protocol definitions and codecs.
- `proto/src/test/kotlin/app/armada/proto/ProtoPlaceholderTest.kt`: Unit test running on desktop JVM without Android dependencies.
- `daemon/build.gradle.kts`: Build configuration for Android library module with compileSdk 35, minSdk 29, depending on `:proto`.
- `daemon/src/main/AndroidManifest.xml`: Manifest for daemon library module.
- `daemon/src/main/kotlin/app/armada/daemon/DaemonPlaceholder.kt`: Placeholder class for root daemon module.
- `cli/build.gradle.kts`: Build configuration for Android library module with compileSdk 35, minSdk 29, depending on `:proto`.
- `cli/src/main/AndroidManifest.xml`: Manifest for CLI client library module.
- `cli/src/main/kotlin/app/armada/cli/CliPlaceholder.kt`: Placeholder class for CLI client module.
- `app/build.gradle.kts`: Build configuration for Android application with compileSdk 35, targetSdk 35, minSdk 29, depending on `:proto`, `:daemon`, `:cli`.
- `app/src/main/AndroidManifest.xml`: Application manifest using `@android:style/Theme.DeviceDefault` without AppCompat.
- `app/src/main/kotlin/app/armada/MainActivity.kt`: Unprivileged MainActivity displaying "Armada" text view with zero third-party UI dependencies.
- `scripts/deps-allowlist.txt`: Allowlist restricting dependencies to Kotlin stdlib 2.4.10 and test-only JUnit 4.13.2.
- `scripts/check-deps.sh`: Bash script enforcing allowlist against `build.gradle.kts` files and verifying absence of `androidx` classes in the debug APK.
- `README.md`: Minimal project overview and build/test/check instructions.

## 4. Deviations from the Brief

- In Android Gradle Plugin 9.0+, Kotlin support for Android modules is built directly into AGP (`com.android.application` and `com.android.library`). Applying `org.jetbrains.kotlin.android` explicitly causes AGP to halt with:
  `The 'org.jetbrains.kotlin.android' plugin is no longer required for Kotlin support since AGP 9.0. Solution: Remove the 'org.jetbrains.kotlin.android' plugin from this project's build file.`
  Consequently, `org.jetbrains.kotlin.android` is omitted from the Android modules, while `org.jetbrains.kotlin.jvm` is applied to `:proto`.
